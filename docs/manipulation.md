# Contact manipulation

The published scene is `scenes/benchmark_v0/scene.xml`, generated by
`benchmark_scene.py`. `ManipulationSimulator` extends the existing Nova simulator;
`ManipulationChunkExecutor` adds measured gripper aperture to ordered Cartesian
waypoints. The action is x/y/z/yaw/pitch/roll/gripper in metres/radians, with
reset-relative orientation and normalized gripper 0=closed, 1=open.

Install Python 3.11, mujoco==2.3.7, numpy==1.26.4, Pillow and pytest for the tested
runtime. From this repository:

```bash
python run_s3_benchmark.py --output evidence/manipulation/<new-run-name>
# Optional offscreen render; requires working EGL/OpenGL:
MUJOCO_GL=egl python run_s3_benchmark.py --render --output evidence/manipulation/<new-render-name>
```

The script performs a deterministic approach/grasp/lift/transport/release and
measures contact grasp, lift, slip, containment, release, settling and distractor
movement. Every output directory must be new. Default execution has no provider,
robot, serial or physical-camera access. Interactive `--viewer` requires a display.

Scene dimensions, grip forces, friction and dynamics are engineering assumptions.
The gripper is a nominal 95 mm proxy, not calibrated physical CAD/TCP. Arm motion
uses a kinematic reference controller; contact success does not establish motor
or real robot behavior. Original `nova2.xml` and S1/S2 execution remain unchanged.

The research snapshot at
[32efb43](https://github.com/shiuhou/mujoco-nova-mujoco/tree/32efb430d17c23e28e068b7751afda48509ab885)
retains model-driven simulation and its original experiment artifacts. Published
main includes the independently verified manipulation and three-view observation layers.
